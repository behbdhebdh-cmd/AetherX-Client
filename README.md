# AetherX Client

AetherX is an internal client for Minecraft.

## How to Use

1. Launch **Minecraft 1.21.1** using the **Forge** mod loader.
2. Open **Extreme Injector** (or your preferred DLL injector).
3. Target the Minecraft process (`javaw.exe`).
4. Inject the compiled AetherX `.dll` file into the process.
5. Once injected, you are ready to go! 
6. Press the **`Insert`** (Einfg) key on your keyboard to open the client menu.
